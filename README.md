# SafeVault
AI powered discreet evidence organization platform for domestic violence survivors.
afeVault is a hackathon MVP demonstrating how a discreet entry screen,
AI-assisted evidence organization, an incident timeline, and a real-time
SOS notification flow can work together in one application.

Safety notice: This is a prototype, not a production-ready
emergency or evidence-preservation service. Do not store real
sensitive evidence or rely on it as the sole way to request emergency
help. The current demo uses a public ntfy topic, which is not private.
